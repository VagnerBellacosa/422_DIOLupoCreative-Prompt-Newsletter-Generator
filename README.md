# 📰 Desafio Criativo – Gerador de Newsletter Interna com IA

## Objetivo

Criar um prompt reutilizável capaz de transformar informações básicas sobre lançamentos de produtos em uma newsletter interna padronizada, clara e acionável.

---

## Problema

A comunicação de novos produtos estava sendo realizada de forma inconsistente através de mensagens isoladas no Slack:

- anúncios sem contexto;
- ausência de links;
- informações técnicas excessivas;
- dúvidas recorrentes das equipes.

O objetivo foi construir um processo simples que permitisse gerar newsletters consistentes mesmo quando preenchidas por pessoas sem experiência em comunicação.

---

## Resultado

O projeto entrega:
